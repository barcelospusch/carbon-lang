# Relatar problemas de segurança

Não publique documentos pessoais ou arquivos confidenciais em issues. Ao relatar uma falha, forneça uma reprodução mínima com dados sintéticos, versão do Carbon, backend, sistema operacional e versões dos runtimes externos.

Carbon não deve ser tratado como sandbox para documentos hostis. Tectonic é iniciado em modo untrusted; Mermaid usa configuração strict, mas a execução de ferramentas externas ainda exige limites e isolamento adequados para serviços públicos.

Se houver recurso de security advisory privado habilitado no repositório, use-o para vulnerabilidades. Caso contrário, entre em contato com o mantenedor por um canal privado antes de divulgar uma exploração.
